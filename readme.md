##  About This Repository
This repository is a living collection of my personal solutions to **LeetCode** problems. It serves as my public notebook for mastering Data Structures, Algorithms, and System Architecture. I push to this repo regularly as I grind through different algorithmic concepts and scale up in difficulty.

##  What's Inside?
My solutions are focused on **clean logic**, **optimal time complexity**, and **mathematical efficiency**. Inside, you will find code that ranges from standard Brute Force implementations to absolute optimal $O(1)$ Space and $O(N)$ Time "cheat code" tricks.

### Concepts Covered:
*   **Arrays & Hashing** 
*   **Two Pointers & Sliding Window** 
*   **Linked Lists** 
*   **Bit Manipulation & Pure Math** 
*   **Dynamic Programming** 

##  Technical Highlights
A few of the core algorithmic techniques I have implemented:
*   *Fast Powering (Binary Exponentiation)* for $O(\log N)$ math.
*   *Tortoise & Hare Pointers* for cycle detection.
*   *Frequency Maps & Array Hashing* for $O(N)$ String processing.
*   *Dynamic Memory Management* in C (`malloc` / `calloc`).

##  Tech Stack
*   **C / C++**: For raw performance, STL mastery, and deep hardware-level memory management.
*   **Java**: For pure Object-Oriented Programming (Polymorphism, Inheritance) and enterprise design.
